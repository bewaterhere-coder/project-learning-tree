# M2.4.1 — Workspace Interaction Polish

## Goal

Keep the M2.4 workspace foundation, but make product naming, theme switching, and pane interaction correct enough for later AI Chat and Node Conversation to reuse the same shell.

## Product naming

User-facing product name is **Learn Tree** / **知识树**. The Projects sidebar title is **Projects** / **项目**. Domain type names such as `LearningNode` and `LearningWorkspace` are unchanged.

## Theme

`workspace.shell.colorScheme` remains the preference. React derives `resolvedTheme` from that preference plus the current OS media query and renders `.shell[data-theme]`. `document.documentElement` is synchronized in `useLayoutEffect`. The boot hint `plt.workspace.theme` is still a resolved light/dark cache only.

## Panes

Long-lived regions use a shared `Pane` / `PaneGroup` / `PaneDivider` model:

- Projects sidebar: horizontal divider, collapse/snap, remembered width
- Active / Archived: vertical divider, collapse/snap, remembered height in pixels
- Inspector: overlay (not a column) that reuses the same divider

Drag uses transient React state. Preferences are written once on release. Semantic persistence is never written by resize, collapse, theme, locale, or menu state.

## Persistence

Preferences stay on `plt.workspace.layout.v2`. `archivedPaneOpen` and `archivedPaneHeight` are additive optional fields; missing values default to `false` / `168`. The semantic store remains `plt.workspace.semantic.v1`.

## Out of scope

AI onboarding, Node Conversation, Chat pane UI, project rename/delete/reorder, Domain lifecycle changes, IndexedDB, accounts.
