# M2.6 — Visual Hierarchy & Contextual Workspace Foundation

Status: Planning. Do not implement UI until this plan is accepted.

This is an implementation plan for a **UI / Interaction Foundation** milestone. It is not a domain redesign and not M3.

Source of design truth: [`docs/design/Learning-Tree-UI-Reference-Study.md`](../design/Learning-Tree-UI-Reference-Study.md).

**Direction (locked):** C — Node-focused contextual workspace.

```text
Project Sidebar (secondary, receded)
+ Tree Canvas (primary)
+ Contextual Workspace → Node Details only
```

M2.6 does **not** create Chat UI, Chat stubs, or Chat preference fields.

Read from current `main`, not from the study alone.

## 4. Shell layout

Flex, not CSS grid.

```text
.shell                         flex column; height 100%
  .shell-header                 ~40px; flex-shrink 0
  .workspace                    flex row; flex 1; min-height 0
    .project-sidebar            width = projectSidebarWidth or 48 collapsed
    .workspace-body             flex 1; min-width 0; flex row
      main.tree-pane            flex 1; min-width 0; PRIMARY
      aside.contextual-workspace  flex-shrink 0; width = inspectorWidth
```

### Resize / collapse

- Sidebar: existing divider, snap/collapse, `projectSidebarOpen` / `projectSidebarWidth`
- Contextual column: `PaneDivider` invert vertical on the **left** edge of the aside; write `inspectorWidth` on release only
- Close (×): `inspectorOpen = false`. No snap-to-zero in P0 (today has none)
- Reopen: `inspector-open` on the canvas right edge, ghost, not a card

### Widths

- Sidebar: keep 200–360, default 260, collapsed 48
- Column: keep 320–420, default 400
- Canvas remaining: `workspace-body width − (inspectorOpen ? inspectorWidth : 0)`
- Measure clamp against `.workspace-body`, not overlay-on-canvas. **No schema change.**

### Narrow viewport (1280×720 is the acceptance size)

- 1280: sidebar 260 + column 400 + canvas ≈ 620 — acceptable
- If the window is tighter: user collapses sidebar first; canvas must not go to 0. If `workspace-body` < `MIN_INSPECTOR_WIDTH + 240`, still clamp column to 320 and let canvas take the rest (`min-width: 0` + XYFlow overflow). No new breakpoint system in P0.
- Do not stack the column under the canvas in P0.

### Persistence contract

`inspectorOpen` / `inspectorWidth` keep the same meaning: whether the right details surface is shown, and how wide it is. Only the CSS positioning changes (overlay → sibling column).

## 7. LearningNode state matrix

Keep `data-node-id`, `data-lifecycle`, `data-blocked`, `data-on-stack`, `data-focus`.

Keep `lifecycle-badge-{id}` as **visually hidden** accessible text so i18n tests can still read translated lifecycle without painting a badge. Keep `blocked-badge-{id}` on the pip with `aria-label` = `node.blocked`.

| State | Background | Border | Ring | Rail | Opacity | Text | Metadata | Edge from parent |
|---|---|---|---|---|---|---|---|---|
| Default open | `--color-bg-node` | 1px default | none | none | 1 | primary 13/600, 2-line | none | default |
| Hover | same | 1px strong **or** tiny shadow, not both | none unless focused | unchanged | 1 | primary | optional lifecycle tooltip | unchanged |
| Focused | same as lifecycle fill | default | 2px selected, offset 0, **no shadow** | unchanged | 1 | primary | pip if blocked | unchanged |
| Active Stack | 4% teal wash | default | none unless focused | 4px accent | 1 | primary | none | active-stack |
| Active leaf | ~8% teal wash | default | none unless focused | 4px accent | 1 | primary | none | active-stack |
| Blocked | lifecycle fill | default | none unless focused | unchanged | 1 | primary | 8px **warning** pip | `edge-blocking` additive |
| Parked | parked tint | default | none unless focused | none | ~0.85 | secondary | none | quiet if off-stack |
| Closed | completed tint | default | none unless focused | none | 1 | muted | none | quiet |

### Combination precedence (must not stack every decoration)

Apply in this order; later does not wipe earlier unless stated.

1. **Lifecycle fill** (open / active / parked / closed) is the base surface. Active-stack wash **replaces** a second heavy green fill — if on stack, use stack wash instead of `lifecycle-active` solid.
2. **Rail** only if `isOnActiveStack`. Closed/parked off-stack: no rail.
3. **Blocked pip** if derived blocked, any lifecycle. Color = warning. Never danger. Pip does not add a second border.
4. **Focus ring** if `isCurrentFocus`. Ring **replaces** hover shadow. Focused+closed still gets the ring so inspect-history works; fill stays completed/muted.
5. **Hover** only when not focused. Never hover-shadow + focus-ring together.

| Combo | Result |
|---|---|
| Focused + Active (on stack, maybe leaf) | stack wash + rail + **blue ring only**. No extra shadow. No lifecycle word. |
| Focused + Blocked | lifecycle/stack fill + warning pip + blue ring. Ring must not be red. |
| Active + Blocked | stack wash + rail + warning pip. No ring unless also focused. |
| Closed + Focused | completed fill, muted text, **blue ring**, no rail unless still on stack (normally not). |
| Parked + Focused | parked fill at 0.85, blue ring, no rail. |
| Focused + Active + Blocked | stack wash + rail + warning pip + blue ring. Maximum allowed chrome. Stop there. |

Forbidden: border + fill + outline + shadow + badge on one node.

Never on canvas: goal, depth, DoD, evidence list, summary, chat, reopen, action buttons, authoring.

## 8. Edge state matrix

View-model only. No domain edge type.

`selectTreeViewModel` may add `isBlocking: parent.blockingChildIds.includes(childId)`.

`toReactFlow` classNames:

| Kind | Class | Stroke | Width | Marker |
|---|---|---|---|---|
| Default | `edge-default` | border-strong ~0.7 | 1px | none |
| Active Stack | `edge-active-stack` | accent teal | 2px (down from 3) | none |
| Blocking | `edge-blocking` additive | inherit path color | inherit | warning tick at child |
| Into parked/closed, off-stack | `edge-quiet` optional | default @ 0.4 | 1px | none |

**Precedence**

1. If the parent→child pair is on Active Stack → `edge-active-stack` (teal 2px)
2. Else if target lifecycle is parked or closed → quiet
3. Else default
4. If `isBlocking` → also `edge-blocking` (tick), **including** on the active-stack path

Edges stay non-reconnectable. No arbitrary links.
