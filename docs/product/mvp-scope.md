# MVP Scope

## In scope

- Create a Learning Project.
- Create one Learning Pass.
- Generate or manually create up to five Core Questions.
- Focus one Learning Node.
- Maintain a separate conversation thread per node.
- Propose and create Blocking Child nodes.
- Move non-blocking questions to Learning Frontier.
- Define and evaluate Definition of Done.
- Attach evidence and a node summary.
- Close a node through a convergence gate.
- Return to a parent or select the next node.
- Persist locally and resume later.

## Explicitly out of scope

- Authentication and user accounts
- Cloud sync
- Collaboration
- Server-side application architecture
- RAG
- Vector databases
- Heavy knowledge graphs
- Course-builder features
- Social features
- Marketplace
- Mobile clients
- General-purpose mind-map editing

## MVP product test

The first MVP succeeds if a user can learn one complex GitHub project through several branching questions, leave, return, and understand both the current focus and the state of previously explored branches without reconstructing context from a long chat transcript.
